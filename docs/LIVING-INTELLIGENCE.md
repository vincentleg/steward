# Living intelligence product checkpoint

## Implemented
- Shared commitment model keeps observed facts, explicit preferences, inferred effects and unknowns separate. Unknown priority, travel/preparation time, financial exposure and people are not invented.
- Typed dependency edges drive direct/dependent consequence explanations. Cycles are bounded and cross-context nodes rejected.
- Meaningful-change assessment distinguishes metadata edits, changes to watch and threatened outcomes. The read-only Calendar observer uses it on its normal polling snapshots.
- Temporal analysis compares actual event times and explicit travel/preparation buffers. Private users can save owner-scoped internal priorities/buffers; these create explicit operational memory, not provider writes. Internal futures remain unverified proposals.
- Synthetic travel futures genuinely change when preparation/travel requirements change. Existing multi-domain option evaluation remains deterministic; Worth to You exposes structured tradeoffs without a universal score.
- Observe Only compresses to zero approval decisions and authorizes no actions. Private conflicts compress to one priority-review headline. Synthetic goal and action predicates still gate Outcome Restored.
- Shared Canvas Core uses only backend observable activity, consequences, alternatives and uncertainty. Persistent asymmetric contour sheets and state-dependent trajectories converge at a decision and return to equilibrium after verified restoration. No reasoning traces.

## Rendering and safety
Native Canvas/CSS; no framework, third-party asset or new dependency. Capped at 30 draws/second, pixel ratio capped at 1.5, intersection and tab visibility pause scheduling. Reduced motion renders state changes without continuous motion. Resizing, navigation restoration and cleanup are handled. Labels and ordinary UI preserve state independently of animation.

One product/codebase: / and /sandbox use the latest synthetic engine; tracking parameters are ignored. /account uses the same primitives with authenticated owner-scoped data locally. Production connected routes remain disabled. No Google credentials or personal tokens are deployed. Calendar remains calendar.events.readonly, Gmail disabled, zero external messages or writes.

## Evidence and limits
Automated tests cover temporal buffers, unknowns, graph propagation, meaningful changes, state mapping, approval invalidation, Observe Only, owner-scoped rules and existing security gates. Browser checks cover motion/state/calm/reload, responsive layouts, reduced motion, accessibility, all ten synthetic scenarios and private account logout/isolation.
