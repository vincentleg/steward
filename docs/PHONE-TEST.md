# Physical-phone test

This uses the existing AgentMail inbox and a free Cloudflare Quick Tunnel. No account creation, purchases, upgrades, auto-top-ups or paid resources are required.

The desktop remains local. `scripts/phone-gateway.js` exposes only `/approve`, `/style.css`, font assets and the health endpoint. Public run creation and event APIs are blocked. The generated HTTPS origin lives only in the ignored `.env`; a tunnel restart generates a different origin, so update the environment and restart Steward before sending another approval.

The local tunnel client and its logs are ignored under `.data/`. Keep the tunnel, gateway and Steward process running throughout the physical test and demo.

## Verification runner

```sh
node --env-file-if-exists=.env scripts/phone-gateway.js
# Start the free tunnel to 127.0.0.1:3002 and privately configure PUBLIC_BASE_URL.
npm start
node --env-file-if-exists=.env scripts/physical-test.js
```

The runner opens a real desktop browser, starts a run and waits for real email approval. It never clicks the approval button on behalf of the user. After detecting iPhone approval, it checks desktop continuation, booking, calendar state, Sarah's sandbox inbox, the payment ledger, voucher evaluation, rejection, cash refund and reload restoration. Then it starts the second run and waits for the second physical approval.

Detailed run evidence is saved privately to `.data/physical-tests/`, never to Git or screenshots. Successful test output contains no credentials, recipient address or approval links.

## AgentMail transport behavior

An inbox-scoped credential may read messages while lacking inbox metadata access. Verify the capabilities actually used rather than requiring organization or inbox administration permissions.

AgentMail appends a service footer to the generated cancellation body. The protocol is the first line of single-line JSON; the footer is excluded before validation. The adapter reads the exact message ID returned by its own authenticated send call and validates the run ID, event type and sandbox flag.

Self-addressed messages are stored as sent rather than producing a second received message. The cancellation is therefore a real, verified AgentMail mailbox event generated by the sandbox airline, not an inbound email from a real airline. This distinction is explicit in its event evidence. The approval email leaves AgentMail for the real recipient; only the physical user's signed POST resumes the live run.
