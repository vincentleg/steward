# Operational World State

One read-only core projection serves synthetic public worlds and owner-scoped private worlds. It surfaces upcoming commitments, actual dependency edges, goals, spending/resource protections, unresolved deviations, deadlines and verified outcome counts. It does not mutate authority or call providers.

The public experience shows the synthetic world's current rules and linked commitments. The private focus view excludes past/cancelled commitments, sorts upcoming commitments and marks priority and travel/preparation assumptions as unknown. Calendar facts are not preferences.

Verified: automated and browser fixture tests, ten public scenarios, shared-device account isolation, three iPhone viewports and mobile accessibility. Real Calendar OAuth and read-only ingestion are connected locally. The harmless external Calendar-change gate remains pending until the specified event is observed automatically; fixtures are not that live gate. Gmail, external actions and production connected mode remain disabled.

Next product work: explicit internal commitment priorities and preparation buffers feeding outcome comparisons, with uncertain assumptions visible and no external writes.
