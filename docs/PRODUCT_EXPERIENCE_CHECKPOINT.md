# Product experience foundation

Built from `58f9627 / temporal-intelligence-v1`, preserving accepted checkpoints and the one-product routes `/`, `/sandbox`, `/account`.

## Delivered

* Permanent Demo entry, separate anonymous world, same LifeEngine and temporal verification. Stable → changed commitment and cancelled flight → dependencies/futures/value → one approval → counteroffer/negotiation → missing receipt → overdue replan → independent synthetic receipt → verified outcome → calm.
* Pause holds the synthetic engine; restart deletes/reseeds; exit deletes Demo state and restores the prior synthetic session. Refresh resumes the Demo bookmark. No real provider is invoked.
* Privacy & Data Protection Center shared by public/private pages, complete implementation-based disclosures, active public-session deletion and owner-scoped JSON exports. See `PRIVACY_DATA_FLOW.md` for storage, processors, controls and limits.
* Stronger layered deformation, circulation and restrained interaction in the existing persistent Canvas Core. Same instance expands into an accessible full-screen evidence conversation surface; background updates remain separate from conversational authority.
* Bounded evidence from actual world, value, alternatives, activity, verification, temporal changes and uncertainty. Public bearer capability and trusted private session independently authorize projections and export.
* Page-only questions and references, cleared on close/logout/reload. No conversion of conversation into permanent memory.
* Replaceable read-only language boundary and speech input/output abstractions. No model has been enabled. Browser speech input requires explicit consent and permission; transcript is reviewed before submission. Audio streams are stopped on close/background/error; no recording or audio-file endpoint.

## Not complete — do not advertise otherwise

**Open-ended conversational intelligence is blocked.** No existing model key or local inference runtime is configured. Chromium exposed a Prompt API stub that echoed input; installed Google Chrome reported its real on-device model unavailable. Neither is working inference. Current UI explicitly says evidence mode; keyword-based evidence retrieval is not a substitute for semantic question answering, general knowledge or natural multi-part synthesis.

**Premium spoken output is blocked.** The tested browser exposed no synthesis voices, and no consistent human-quality Steward voice has been verified. The output interface is disabled. No imitation, cloned voice, paid speech API or new infrastructure was added. Real microphone transcription and premium voice quality have not been certified by fixture tests.

Calendar proactive validation remains **PENDING**. Calendar stays privately read-only; Gmail remains disabled. No new spend.

## Permanent regression requirements

Demo, Privacy, clickable living Core, existing URLs, synthetic/owner separation and authority boundaries must survive future releases. Do not remove these controls to simplify a subsequent phase. Update privacy disclosures when actual processing changes. Do not enable inference or speech output without disclosing processing and passing grounded-answer/voice-quality gates.
